## 三、新的调用链（关键）

```asm
; 1) 造一个中间对象
0x7547a5e4a4  ldr  x0, [x28]
0x7547a5e4a8  bl   #0x7542af19cc      ; 返回 x0
0x7547a5e4b0  mov  x1, x21            ; x21 = 前一个中间对象
0x7547a5e4b8  mov  x24, x0
0x7547a5e4bc  bl   #0x75436f2138      ; 包一层

; 2) 真正的字典构造
0x7547a5e4c0  ldr  x3, [x26]
0x7547a5e4c4  mov  x0, x22            ; = 参数2（CommandId）
0x7547a5e4c8  mov  x1, x23            ; = 某个已存在的字典片段
0x7547a5e4cc  mov  x2, x24
0x7547a5e4d0  bl   #0x7543427748      ; ← **返回 _gainActGaugeAmountDict**
0x7547a5e4d8  str  x0, [x20, #0x18]
```

### 途中遇到的一处复用

`0x7547a5e43c` 起有一段：若全局缓存里已有值（`cbnz x23`）就跳过构造，
否则走 `bl #0x75436f21d8` 造出来再 `str x23, [x8, #8]` 写回缓存。

⇒ **存在一层全局缓存**，第一次构造和后续复用走的路径不同。**[码]**
