## 1. 结构：三胞胎

| thunk 起点 | 长度 | 尾部跳转目标 |
|--:|--:|:--|
| `0x7543427748` | 0x54 | **`0x754342a684`** ← 构造函数实际调用的就是这个 |
| `0x754342779c` | 0x54 | `0x754342aa38` |
| `0x75434277f0` | 0x54 | `0x754342adec` |

三份代码**逐字节相同**，只有最后一条 `b` 的偏移不同：

```asm
str  x30, [sp, #-0x30]!
stp  x22, x21, [sp, #0x10]
stp  x20, x19, [sp, #0x20]
ldr  x8, [x3, #0x38]        ; 取一个「延迟初始化」字段
mov  x19, x2
mov  x20, x1
mov  x21, x0
cbnz x8, +0x14              ; 已初始化就跳过
mov  x0, x3
mov  x22, x3
bl   #0x7542aa40c8          ; ← 延迟初始化
ldr  x8, [x22, #0x38]
ldr  x4, [x8, #0x18]        ; x4 = 初始化结果的 +0x18
mov  x0, x21
mov  x1, x20
mov  x2, x19
...
mov  x3, xzr
ldr  x30, [sp], #0x30
b    #0x754342a684          ; 尾调用
```

## 2. 这说明什么

| 结论 | 依据 |
|:--|:--|
| 这三个都是**转发壳（thunk）**，不含业务逻辑 | 全函数只有寄存器搬运 + 尾跳 **[码]** |
| 真正的实现在 `0x754342a684` 一族 | 三条 `b` 目标互不相同 **[码]** |
| 存在**延迟初始化**（`[x3+0x38]` 为空才调 `0x7542aa40c8`） | `cbnz` 分支 **[码]** |
| 第四个参数 `x4 = [初值+0x18]` 是运行期拿到的 | `ldr x4,[x8,#0x18]` **[码]** |

**`out/gainbuilder_0x7543427748.consts` 为空** —— 这一层没有任何立即数。

## 3. 与构造函数的关系

构造函数 `0x7547a5e4d0` 调的是 **`0x7543427748`（第一个 thunk）**
⇒ 因而真实实现是 **`0x754342a684`**。

另两个 thunk（`0x754342aa38` / `0x754342adec`）是**同一模式的其他重载**，
