## 4. 这意味着：演目逻辑不在这一层

构造函数那条链：

```

  └─ bl 0x7543427748        (thunk，三胞胎之一)
```

**`0x7544815880` 是这条链上最后一个未解点。**

那么真正要找的是**构造函数的调用方**，而不是继续往下钻。
